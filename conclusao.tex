\chapter{Conclusão}

Este projeto de TCC propõe o desenvolvimento e a avaliação de uma arquitetura plugável para extração estruturada de informações em provas objetivas manuscritas. O foco está na comparação entre dois arranjos técnicos de uso de modelos multimodais: um modelo aberto hospedado em servidor próprio e um modelo proprietário acessado por API externa. O aplicativo móvel será utilizado apenas para captura das imagens e visualização dos resultados, enquanto o processamento será realizado pelo backend e pelos provedores de IA.

A expectativa de conclusão é identificar, com base no experimento planejado, qual abordagem apresenta melhor equilíbrio entre acurácia, validade da saída JSON, latência, custo operacional, privacidade, controle de infraestrutura, robustez e necessidade de validação humana. Assim, o resultado esperado não é apenas demonstrar um aplicativo funcionando, mas produzir uma análise comparativa útil para decisões de arquitetura em Sistemas de Informação.

O estudo permanecerá limitado ao conjunto de provas, modelos, infraestrutura e métricas definidos no projeto. Mesmo assim, espera-se que a avaliação permita discutir de forma objetiva os trade-offs entre utilizar um modelo multimodal aberto em servidor próprio e consumir um modelo multimodal proprietário por API externa.
